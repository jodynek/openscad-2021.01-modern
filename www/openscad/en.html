OpenSCAD 2021.01 · modernized build

Script-based 3D CAD: describe a part in the OpenSCAD language and the program computes it and exports STL or 3MF. The last tagged release, 2021.01, built with current tools – Visual Studio 2026, CMake + vcpkg, C++17 and Qt 6 with dark mode – with an installer for Windows 11.

What it looks like

Editor, preview and console in dark mode (the Fusion style follows the Windows setting). The logo.scad example on the left, the result on the right.

Features

Modelling in code

Describe a part with a short script: cubes, spheres, cylinders, extruded 2D profiles, union, difference and intersection. Change a number and the part changes – ideal for parametric parts for 3D printing.

Same results as the official 2021.01

Neither the language nor the CGAL geometry kernel changed. Your existing files and libraries evaluate exactly the same, just in a program built for today's Windows.

Qt 6 and dark mode

The interface runs on Qt 6.10 with the Fusion style, which follows the light or dark Windows theme; the editor and preview colour schemes switch with it.

Export for printer and mill

STL, 3MF, AMF, OFF, DXF, SVG, PDF and PNG. Send a model to OctoPrint or a print service straight from the program.

Customizer

Variables of the script appear as a form with sliders and drop-downs; parameter sets can be saved and shared with the model.

Command line

openscad-cli.exe renders and exports without a window – for batches, scripts and CI. Text works thanks to the bundled Liberation fonts and the fonts installed in Windows.

Installer for Windows 11

Installs the GUI, the command-line build, examples, fonts and libraries, offers the .scad file association and a PATH entry; the Visual C++ runtime is bundled and installed only when missing.

Simple build

One PowerShell script fetches vcpkg, builds all libraries and the program with Visual Studio 2022 or 2026. On Ubuntu 24.04 the distribution packages and two CMake commands are enough.

Open source

GPL 2 or later; the sources and the history of changes against the pristine 2021.01 release are on GitHub; Windows and Linux are built automatically on GitHub Actions.

All features

Language and modelling
  • Solids: cube, sphere, cylinder, polyhedron; 2D: circle, square, polygon, text; import of STL, OFF, AMF, 3MF, DXF and SVG
  • Boolean operations union, difference, intersection; hull, minkowski, offset, projection
  • Transformations translate, rotate, scale, mirror, multmatrix, color, resize
  • linear_extrude and rotate_extrude from 2D profiles, with twist and scale
  • Modules, functions, recursion, list comprehensions, let, each, assert, echo
  • Curve resolution via $fn, $fa and $fs; preview vs. full render (F5 / F6)
  • include and use for libraries, OPENSCADPATH and the bundled MCAD library
  • text() with any system font and the Liberation fonts bundled with the program
Editor and GUI
  • QScintilla 2.14 editor with highlighting, code folding, auto-indent, bookmarks and find/replace
  • Several open files in tabs, automatic reload when the file changes on disk (F4)
  • 3D preview with OpenCSG, orthographic and perspective camera, axes, edges, scale markers, views from the keyboard (Ctrl+4 to Ctrl+0)
  • Console with echo output and errors, Error-Log with filter, object tree and highlighting of selected parts (#, %, !, *)
  • Customizer: parameters with ranges as sliders, toggles and drop-downs, parameter sets saved as JSON
  • Colour schemes for the editor and the 3D window, defaults follow the light or dark Windows theme
  • Welcome screen with recent files and examples
  • Preferences: font, editor behaviour, preview options, OctoPrint, backups
Export, import and printing
  • Export STL (ASCII and binary), 3MF, AMF, OFF, DXF, SVG, PDF, PNG; preview image export with a chosen size and camera
  • Send a model to OctoPrint (upload and optionally start the print) or to a 3D print service; only on your request
  • Validity check of the solid for printing (Design › Check Validity)
  • Command line: openscad-cli.exe -o part.stl part.scad, parameters via -D, --export-format, -p for Customizer sets, PNG with --imgsize and --camera
What is different in the modernized build
  • Visual Studio 2022 / 2026 (MSVC), CMake 4 with presets, dependencies from a vcpkg manifest – no hunting for libraries
  • C++17: GLib replaced by own UTF-8 helpers, parts of Boost replaced by std::filesystem, std::optional, std::variant and std::regex; Boost header-only + Program.Options
  • Qt 6.10 (Qt 5 removed), QScintilla 2.14, OpenGL through QOpenGLWidget; Fusion style with dark-mode support
  • Current libraries: CGAL 5.6, Boost 1.92, Eigen 5, GLEW 2.3, libxml2, libzip, harfbuzz, fontconfig
  • Crash fixes: the silent crash on an empty resource path now reports an error, a dangling pointer in search() is fixed
  • Inno Setup installer, smoke tests, GitHub Actions for Windows and Linux, code signing prepared (SignPath Foundation)
  • Linux: Ubuntu 24.04 from distribution packages (Qt 6.4, CGAL 5.6), clean build verified in Docker

Windows

Installer, Windows 10 and 11 (64-bit)
  • Run the installer; it installs to Program Files, or just for you without administrator rights (choice in the wizard or /CURRENTUSER).
  • Contains the GUI OpenSCAD.exe, the command-line openscad-cli.exe, examples, fonts and libraries.

Download for Windows

Linux and source code

Ubuntu 24.04 / Debian 12, build from source
  • sudo ./tools/linux-deps.sh installs the compiler, CMake, CGAL, Qt 6 and QScintilla from distribution packages.
  • cmake --preset linux-release and cmake --build --preset linux-release build the GUI and the command-line version.
  • On Windows with Visual Studio 2022/2026 run build-msvc.ps1; the first run builds the libraries (about an hour), later runs take seconds.
Repository on GitHub
Releases with the installer are also on GitHub Releases.

Silent install: OpenSCAD-2021.01-modern.1-win64-setup.exe /VERYSILENT /NORESTART. Uninstall through Windows Settings › Apps.
